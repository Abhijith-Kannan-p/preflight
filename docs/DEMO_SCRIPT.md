# Demo script (3 minutes)

For the Round 2 judges and the Round 3 video. Open https://preflight-eight-smoky.vercel.app
a minute before you start, so the free server is awake.

| Time | Do | Say |
|---|---|---|
| 0:00 | Landing page, scroll the hero once | "Content now comes from employees, agencies and AI tools. Off-brand wording, outdated facts and unsupported claims go live before the brand owner sees them. Preflight is the review gate before publication: grounded, explainable, human-controlled." |
| 0:15 | **Try the live demo** → **LinkedIn post (off-brand)** → **Run Preflight** | "This is the post from our Round 1 plan. No sign-up: I'm abhi1, a creator at the fictional fintech PayWise." |
| 0:25 | Point at the checkers ticking green, then the highlights | "Deterministic checks land in under two seconds; the Claim Ledger and tone follow. Every highlight is a finding, coloured by severity." |
| 0:40 | Open the **CLM-04** card | "'100% secure' breaks rule CLM-04, page 14 of the brand book. The closest approved fact is F-112, bank-grade AES-256 encryption, and the suggestion keeps the meaning: drift 0.06." |
| 0:55 | Open the **CLM-03** card, then the **Claim Ledger** tab, expand one row | "'Under 5 seconds' was true until 1 September. F-086 was superseded by F-087, so it's outdated, not just unsupported. The LLM never decides truth: retrieval, a local NLI model, exact numbers and a verbatim quote do. Green rows are claims we confirmed." |
| 1:20 | **AI disclosure** tab | "Every review says exactly which AI ran, and confidential terms are masked before any external call." |
| 1:30 | **Accept** the suggestions → **Re-check with N changes** | "Nothing is applied silently. Accepting stages a change; re-check creates revision 2." |
| 1:45 | Score rises; **Revisions** tab | "24 to 97. The diff shows exactly what changed and which findings it resolved." |
| 1:55 | **Submit for approval** → role switcher → **abhi4** → **Approve** | "Critical findings block submission. Now I'm the approver; overriding a critical would need a written reason." |
| 2:15 | **View Review Receipt** | "A one-page record: who, when, what was checked, what AI was used, and a verified hash-chained audit log. Shareable and downloadable." |
| 2:30 | **Insights**, then **Evaluation** | "Insights show which rules fire and get disputed. And we measure the Claim Ledger honestly: 150 labelled claims, 92% accuracy, every failure case listed." |
| 2:45 | **Settings** (abhi5) → API keys and webhooks | "CMSs call the same engine through a keyed REST API, and approvals fire signed webhooks, Slack included." |
| 2:55 | Close | "Round 3 adds visual review, governance intelligence and Brand Autopilot. Preflight: content cleared before it goes live." |

Backup if the server is slow: the clean sample ("Clean post (passes)") is cached after its
first run and returns instantly.
