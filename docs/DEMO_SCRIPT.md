# Demo script (5 minutes)

For the Round 3 video and a live walkthrough. Open https://preflight-eight-smoky.vercel.app a
minute before you start, so the free server is awake. Each browser gets its own private
PayWise workspace, so the demo can be repeated from a fresh window.

| Time | Do | Say |
|---|---|---|
| 0:00 | Landing page | "Content now comes from employees, agencies and AI tools. Off-brand wording, outdated facts and unsupported claims go live before the brand owner sees them. Preflight is the proof desk before publication: grounded, explainable, human-controlled." |
| 0:15 | **Open the demo desk** → **LinkedIn post (off-brand)** → **Run Preflight** | "No sign-up: I'm abhi1, a creator at the fictional fintech PayWise, in my own private copy of the workspace." |
| 0:25 | The preflight checklist ticking, then the margin notes | "Deterministic checks land first; the Claim Ledger and tone follow. Each finding is a margin note on the exact words, with its rule and source page." |
| 0:40 | The **CLM-04** note, then the outdated settlement-time note, then the **Claim Ledger** tab | "'100% secure' breaks CLM-04, brand book page 14; the suggestion keeps the meaning. 'Under 5 seconds' was true until September: F-086 was superseded by F-087, so it is outdated. The LLM never decides truth: retrieval, a local NLI model, exact numbers and a verbatim quote do." |
| 1:05 | **Accept** the suggestions → **Re-check** | "Nothing is applied silently. Re-check creates revision 2: 24 to 97." |
| 1:15 | **Submit for approval** → role switcher **abhi4** → **Approve** → stamp → **Clearance Certificate** | "The approver clears it; the stamp and the certificate record who, when, against which rules and which AI, with a verified audit hash." |
| 1:40 | **New review** → **Festive banner (image)** → Run | "Improvement one: visuals. Text in the image is read and checked like any draft, and colours, contrast and the logo are measured on the pixels. 'India's #1' and '100% secure' are in the image; the pink block is off-palette; the small line fails contrast." |
| 2:15 | Switch to **abhi3** → **Governance** → Guideline Health | "Improvement two: governance. This rule is flagged as ambiguous: writers dispute it three times out of four, and their reasons are grouped. 'Suggest clearer wording' drafts a rewrite that a person edits and publishes as a new version; after DSC-01 was reworded its disputes fell from 80% to zero." |
| 2:45 | **Stale-Content Radar** → **Simulate fact update on F-087** → **Re-check now** | "When an approved fact changes, every cleared post that relied on it appears here, with the exact sentence, and its author is notified." |
| 3:10 | **Creator Coach** | "And each writer sees their own recurring mistakes and two or three tips before they write." |
| 3:25 | **Rulebook → Compiler → Compile the sample brand book** | "Improvement three: Brand Autopilot. A 20-page brand book becomes typed rules, each beside the sentence and page it came from, compared with the rulebook. Nothing is active until a brand manager accepts it." Accept "revolutionary". |
| 3:55 | **Rulebook → Voice** | "The voice PayWise actually publishes, learned from approved posts, against the hand-set targets. Adopting it creates a new voice-profile version." |
| 4:15 | **Evaluation** tabs | "Everything is measured: claims, full drafts, visuals and the compiler, with a held-out set and every failure listed." |
| 4:35 | **Settings** (abhi5) → webhooks delivery log | "CMSs call the same engine through a keyed REST API; approvals, publications and critical findings fire signed webhooks with retries." |
| 4:50 | Close | "Preflight: content cleared before it goes live." |

Backup if the server is slow: "Clean post (passes)" and the samples above return cached
results after their first run (labelled "cached result").
