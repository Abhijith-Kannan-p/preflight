# User testing

Short moderated tests with 3 to 5 people who have not seen Preflight. Give each person the
live link and one task at a time; do not explain the interface. Note what they do, how long
it takes and what they say. Fill in one table per participant.

## Tasks

1. "Check this LinkedIn post before it goes out." (They should find the samples or paste
   text and run Preflight.)
2. "Which problem would stop this post from being approved, and why?" (CLM-04 or CLM-01;
   can they explain the rule and source?)
3. "Fix the post and get it ready for approval." (Accept suggestions, re-check, submit.)
4. "You are now the approver. Approve it and find the proof that it was approved."
   (Role switcher, approve, receipt.)
5. "Is the claim about settlement time true?" (Claim Ledger, outdated verdict, F-087.)
